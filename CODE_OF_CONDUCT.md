# Code of conduct

Be decent. Assume good faith. Critique code, not people.

Unacceptable: harassment, personal attacks, sustained disruption, publishing
someone's private information.

Report problems to the repository owner via a GitHub issue or direct message.
Maintainers may remove comments, commits, and contributions that do not follow
this, and may block accounts for repeated or severe behaviour.

Adapted, informally, from the spirit of the Contributor Covenant.
